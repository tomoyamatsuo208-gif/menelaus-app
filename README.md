# menelaus

menelaus is a social and outdoor life logging app concept inspired by Instagram-style UX, with route recording, weather, AI planning, chat, journals, and analytics for travel and outdoor activity.

## Included in this prototype
- Instagram-like feed and story cards
- Route map and activity summary panel
- Chat panel and AI travel planner mockup
- Architecture overview
- Full 60-feature catalog

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes
This project was created as a frontend prototype and design system for the requested app specification.
